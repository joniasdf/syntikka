# Syntikka – syntetisaattorin oppimispeli

Selainpeli, jossa nuotit valuvat alas oikeiden koskettimien kohdalle (Synthesia-tyyliin). Sopii näytön tai television alle oikean syntikan kanssa.

## Käyttö

1. Avaa sivu Chromessa tai Edgessä (MIDI ja mikrofoni toimivat parhaiten näissä).
2. Valitse kappale ja pelitapa.
3. MIDI-koskettimistolla: anna selaimen käyttää MIDI-laitetta.
4. Ilman MIDI:tä (esim. Casio CT-615): käytä mikrofonikuuntelua – ohje asetuksissa.

## Casio CT-615

Pika-asetuksissa on valmis CT-615-esiasetus. Katso myös [ohje-casio-ct615.md](ohje-casio-ct615.md).

## Tekijänoikeudet

Mukana olevat kappaleet ovat tekijänoikeusvapaita klassikoita, kansanlauluja ja lastenlauluja. Voit ladata omia MIDI-tiedostoja pelin asetuksista.
